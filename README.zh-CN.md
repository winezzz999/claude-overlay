## 为什么做这个

有时候你要问的东西**就在屏幕上** —— 一条报错、一张图表、一个看着不对劲的界面。截图、保存、找到文件、上传、再切到聊天窗口……为了一个可能第三步就忘了的问题，绕太多弯了。

`claude-overlay` 把它压缩成：**按一个键，拖个框，打字。**

它平时就是一个半透明的小窗口钉在所有东西上面 —— 不占任务栏、没有标题栏、不用来回切窗口。

## 功能

| | |
|---|---|
| **始终置顶** | 无边框、半透明、可拖动。永远不会被盖住。 |
| **打字对话** | 回答流式显示，多轮之间保持上下文。 |
| **框选提问** | 按 <kbd>·</kbd>（数字 <kbd>1</kbd> 左边那个键）。整屏变暗，你框的区域保持明亮，然后直接打字提问。 |
| **全分辨率截图** | 发给模型的是屏幕的真实像素，不是缩小的预览图。 |
| **可以重框** | 框得不满意？再拖一个就行 —— 没发送之前什么都不锁定。 |
| **对话历史** | 对话在重启后保留 —— 不仅你自己看得到，Claude 也记得。标题条的 + 和 ≡ 用来新建、切换、删除。 |
| **记住你的偏好** | 背景颜色和透明度保存在 `config.json`。 |

## 环境要求

- **Python 3.10+**（`claude-agent-sdk` 的要求）
- **Windows** —— 抢键盘焦点那段直接调用了 Win32 API
- 一个能连通的 Claude 兼容端点，令牌放在 `~/.claude/settings.json` 里

## 快速开始

```bash
pip install -r requirements.txt
python overlay.py
```

然后**打字回车**，或者**先按 <kbd>·</kbd> 拖一个框**。

## 用法

### 问屏幕上的东西

1. 按 <kbd>·</kbd> —— 整屏变暗，**你框住的区域保持正常亮度**。
2. 拖出一个矩形。改主意了就再拖一个。
3. 松手 —— 悬浮窗跳到最前，输入框拿到光标。
4. 打字提问，回车。截图随问题一起发出去。
5. 任意阶段按 <kbd>Esc</kbd> 或点右键 = 整个取消。

> **框选区别盖住悬浮窗自己** —— 它浮在屏幕上层，会被一起拍进去。

### 问别的东西

直接打字。这条走的是一个持续的 Claude 会话，所以能记住上下文，也能读项目里的文件。

### 对话管理

- 标题条的 **`+`** 把当前对话存档，另起一个空对话
- **`≡`** 打开历史列表 —— 点一条切回去，或删掉它
- 关掉程序一切照存：下次启动恢复上次的对话，Claude 也从上次接着聊

历史存在代码旁的 `history.json` 里（不会推送到仓库）。每条对话的标题自动取自第一个问题。

这两条是**故意分开的两个通道** —— 原因见下。

## 工作原理

```
                    ┌─────────────────┐
   打字 + 回车 ─────▶│  agent.py       │  claude-agent-sdk
                    │  ClaudeSession  │  持续会话，有工具、有上下文
                    └─────────────────┘
                    ┌─────────────────┐
  · + 框选 + 回车 ──▶│  vision.py      │  anthropic SDK
                    │  VisionSession  │  一次性，图 + 文字，不带历史
                    └─────────────────┘
```

截图提问是**故意做成一次性**的：它既不继承、也不污染聊天历史。这样「这条报错什么意思」就不会把一场长代码对话带跑偏。

### 两个值得一提的细节

**变暗不能用 `-alpha`。** 最直觉的做法是拿一个半透明 `Toplevel` 盖住屏幕 —— 但不行：`-alpha` 作用于**整个窗口**，你框选的区域会跟着一起变暗。`capture.py` 的做法是：先截图，把其中一份调暗，把调暗那份铺在 `Canvas` 上当背景，再把**原图**的对应像素贴回选区 —— 相当于在暗屏上挖了个亮洞。

**DPI 缩放。** 显示器设成 125% 时，Tk 的坐标空间和截图的实际像素**不是一回事**（开发这台机器上是 2048×1280 对 2560×1600）。`capture.py` 在运行时算这个比例（`截图宽 / Tk屏宽`），而不是写死数字，所以换显示器或改缩放都不用动代码。

## 文件说明

| 文件 | 作用 |
|---|---|
| `overlay.py` | 悬浮窗界面、热键处理、阶段切换 |
| `history.py` | 对话历史：把消息和会话 ID 存在 `history.json` |
| `agent.py` | 文字对话，走 `claude-agent-sdk`（流式、保持上下文） |
| `capture.py` | 全屏框选层：变暗、亮洞、DPI 坐标换算 |
| `vision.py` | 截图提问，走 `anthropic` SDK（流式） |
| `test_sdk.py`、`test_vision.py` | 两条通道各自的验证脚本 |

## 配置

第一次在 ⚙ 面板里改背景色或透明度时，会生成 `config.json`。删掉它就是恢复默认值。

`history.json` 存着你的对话记录 —— 它在 .gitignore 里，不会离开你的电脑。

密钥**不会**出现在这个仓库里 —— 都是运行时从 `~/.claude/settings.json` 读的。

## 已知限制

- **只支持 Windows。** 抢焦点那段直接用了 Win32 API。
- **悬浮窗可能被拍进截图**，如果框选区盖住了它。
- **截图提问的首字要等 5～7 秒** —— 模型得先看图。聊天区会立刻显示 `🤖 Claude：`，所以不会像卡死。
- **热键在 `capture.py` 里写死**。改之前先看那里的注释 —— 有两个不太直觉的坑。
